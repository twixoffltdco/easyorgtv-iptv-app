General Questions

Easyorgtv is a free, open-source IPTV channel aggregator that searches the internet for publicly available live TV streams. It provides a unified interface to browse, search, and watch channels from around the world.

Unlike traditional IPTV services, Easyorgtv does not host any content - it simply indexes and organizes publicly available streams.

Yes, Easyorgtv is completely free and open-source. There are no subscriptions, no ads, and no hidden fees. You can self-host it on your own server or use the public instance.

Easyorgtv uses a crawler system that searches the internet for publicly available M3U/M3U8 playlists. These playlists contain links to live TV streams that broadcasters have made publicly accessible.

We do not source channels from any specific provider or database - our system independently discovers and indexes streams from across the web.

Playback Issues

Streams can stop working for several reasons:

  • The broadcaster changed the stream URL
  • The stream is geo-restricted in your region
  • The stream requires authentication
  • Server maintenance or technical issues
  • High traffic causing temporary unavailability

Try refreshing the channel list or checking back later. Our crawler periodically updates the stream database.

Buffering issues are usually related to network conditions:

  • Check your internet connection speed
  • Try a different stream quality if available
  • Close other bandwidth-heavy applications
  • Try using a VPN if the stream is slow from your location
  • Wait a few moments and try again

Technical Questions

Self-hosting is simple:

  1. Clone the repository: git clone https://github.com/easyorgtv/easyorgtv.git
  2. Install dependencies: npm install
  3. Start the server: npm start

The server runs on port 3000 by default. Set the PORT environment variable to change it.

You can add custom playlist sources by modifying the server/crawler.js file. Add URLs to the CRAWL_SOURCES array:

CRAWL_SOURCES.push('https://example.com/playlist.m3u');

The crawler will automatically fetch and parse channels from your custom sources on the next scan.

Easyorgtv works on all modern browsers:

  • Google Chrome (recommended)
  • Mozilla Firefox
  • Microsoft Edge
  • Safari (with native HLS support)
  • Opera

For the best experience, use the latest version of Chrome or Firefox.

The crawler runs automatically every 6 hours to discover new channels and validate existing streams. You can also trigger a manual scan via the API at POST /api/scan.

Legal Questions

Easyorgtv indexes publicly available streams from the internet. We do not host any content ourselves. The legality of watching specific streams depends on your local laws and the licensing of the content.

We recommend only watching content that is legally available in your region. Please refer to our Terms of Service for more information.

If you are a copyright holder and believe your content is being indexed without authorization, please contact us with the following information:

  • Your contact information
  • Description of the copyrighted work
  • The specific channel or stream URL
  • A statement of good faith belief that use is not authorized

We will promptly remove any infringing content from our index.
