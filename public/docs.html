Documentation

Complete technical documentation for Easyorgtv - an IPTV channel aggregator with internet-wide search capabilities.

Getting Started

Easyorgtv is a self-hosted IPTV channel aggregator that searches the internet for publicly available streams and provides a unified interface for viewing them.

Installation

Clone the repository and install dependencies:

git clone https://github.com/easyorgtv/easyorgtv.git cd easyorgtv npm install

Running the Server

Start the development server:

npm start

The server will start on http://localhost:3000 by default.

Architecture

Easyorgtv consists of three main components:

  • Crawler - Searches the internet for M3U/M3U8 playlists and validates streams
  • Parser - Extracts channel metadata from playlist files (name, logo, category, etc.)
  • API Server - Express.js server providing REST endpoints and serving the frontend

Data Flow

  1. Crawler fetches playlists from configured sources
  2. Parser extracts channel information and validates URLs
  3. Channels are stored in an in-memory database
  4. Frontend queries the API and displays channels
  5. User clicks play, HLS.js loads the stream

API Reference

All API endpoints return JSON data.

GET /api/channels

Get paginated list of all channels. Supports filtering by category, country, and language.

GET /api/channels/search?q={query}

Search channels by name, category, or country.

GET /api/channels/:id

Get a single channel by ID.

GET /api/categories

Get list of all categories with channel counts.

GET /api/countries

Get list of all countries with channel counts.

GET /api/playlist

Export all channels as an M3U playlist file.

GET /api/stats

Get system statistics (total channels, categories, countries, last scan time).

POST /api/scan

Trigger a manual scan for new channels.

Query Parameters

Parameter Type Description
page integer Page number (default: 1)
limit integer Items per page (default: 50)
category string Filter by category name
country string Filter by country code
language string Filter by language

Channel Object

Each channel object contains the following fields:

{ "id": "nasa-tv-public-abc123", "name": "NASA TV Public", "url": "https://example.com/stream.m3u8", "logo": "https://example.com/logo.png", "category": "Science", "country": "US", "language": "English", "tvgId": "nasa.tv", "tvgName": "NASA TV", "source": "https://example.com/playlist.m3u" }

M3U Playlist Format

Easyorgtv supports standard M3U and extended M3U (M3U8) formats with the following tags:

  • #EXTM3U - Header tag
  • #EXTINF - Channel information with duration and attributes
  • tvg-logo - Channel logo URL
  • tvg-id - Channel identifier for EPG
  • tvg-name - Channel display name
  • tvg-country - Country code
  • tvg-language - Language
  • group-title - Category/group name

Example Playlist

#EXTM3U #EXTINF:-1 tvg-id="nasa.tv" tvg-name="NASA TV" tvg-logo="https://example.com/nasa.png" group-title="Science",NASA TV https://ntv1.akamaized.net/hls/live/2014075/NASA-NTV1-HLS/master.m3u8 #EXTINF:-1 tvg-name="France 24" group-title="News",France 24 https://static.france24.com/live/F24_EN_LO_HLS/live_web.m3u8

Integration with Players

Export your playlist and use it with any IPTV player:

VLC Media Player

  1. Download the M3U playlist from /api/playlist
  2. Open VLC and go to Media → Open Network Stream
  3. Paste the playlist URL or open the downloaded file

Kodi

  1. Install the PVR IPTV Simple Client addon
  2. Configure the addon with the playlist URL
  3. Restart Kodi to load channels

Programmatic Access

// Fetch channels via API const response = await fetch('http://localhost:3000/api/channels'); const { data, pagination } = await response.json(); // Get M3U playlist const playlist = await fetch('http://localhost:3000/api/playlist'); const m3u = await playlist.text();
